# Claude Opus restructuring consensus

Date: 2026-07-28
Model: Claude Opus
Method: two bounded read-only review rounds against the presentation outline and the user's corrected objective.

## Shared diagnosis

The prior narrative sold the demonstration itself. It read as a Google Sheets project-manager product pitch because the audience, deliverables, proof order, and close were all bound to the project-reporting example. The example also needed a clearer provenance label: it is a self-built sample, not client work.

## Agreed restructuring

Use an untimed hero followed by eight narrated stages:

1. When the spreadsheet works—but the workflow around it does not.
2. A working example I built: one Sheet, three controlled workflows.
3. The pattern transfers: structured fields, Apps Script logic, governed AI.
4. Start with one decision, then map data and acceptance checks.
5. Back to the example: useful output without invented precision.
6. AI drafts language. Deterministic logic owns the numbers.
7. Build the smallest useful system inside tools you already use.
8. Show me the Sheet process you still run by hand.

The working Sheet is early proof of the method, then the story deliberately moves outward to the transferable architecture, engagement process, decision boundaries, and bounded offer. The final call to action asks about the prospect's existing recurring Sheet process.
